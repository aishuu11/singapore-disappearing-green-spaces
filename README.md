# Singapore's Disappearing Green Spaces

An interactive data story exploring how Singapore's parks, nature reserves, and
developed areas have changed over time.

The project combines maps, comparisons, and a scroll-driven timeline to help
readers understand where green spaces are located, how access differs between
regions, and how Singapore's landscape is changing.

## Planned story sections

- An overview map of parks, nature reserves, and development areas
- A comparison of green-space access by region
- Before-and-after maps showing landscape changes
- A scroll-driven timeline explaining important changes
- Source notes and methodology explaining the data and limitations

## Tech stack

- React
- JavaScript
- Vite
- D3.js
- MapLibre GL

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Run linting:

```bash
npm run lint
```

## Project structure

```text
src/
├── components/   Reusable story and visualization components
├── data/         Cleaned datasets used by the story
├── types/        Shared data definitions, if needed
└── utils/        Data and visualization helpers

```
